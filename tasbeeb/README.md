# التسبيب (Tasbeeb)

تطبيق آيفون وآيباد أصلي (SwiftUI) بتصميم «محادثة»: يلصق القاضي المحضر ويرفق صور البينات،
فيصنّف الدعوى ويقرأ المرفقات على الجهاز ويسأل عن الناقص فقط، ثم يعطي التسبيب جاهزاً.

- `ios/` — مشروع التطبيق (XcodeGen: `ios/project.yml`). المحرك في `ios/Tasbeeb/Resources/engine.js`.
- `pc/` — نسخة الكمبيوتر (ملف HTML واحد يعمل دون إنترنت) ومصادرها:
  `engine.js` المحرك المشترك، و`src.html` + `att.js` + `build.py` لبناء الملف الواحد.

المحرك واحد للنسختين: أي تعديل في القوالب يُعمل في `pc/engine.js` ثم يُنسخ إلى `ios/Tasbeeb/Resources/engine.js`.
لا يتصل التطبيق بالإنترنت، وتُحفظ القضايا على الجهاز فقط.

البناء والرفع إلى TestFlight: `.github/workflows/apps-testflight.yml` (التطبيق: tasbeeb).
